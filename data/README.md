# Data

This folder contains datasets and training data for fine-tuning QA models.

## Structure

- **raw/**: Original, unprocessed datasets
- **processed/**: Cleaned and preprocessed datasets ready for training
- **splits/**: Train, validation, and test splits

## Supported Formats

- JSON
- CSV
- JSONL (JSON Lines)
- Parquet

## Usage

Place your QA datasets in this directory following the structure above. Ensure your data follows the standard QA format with questions, contexts, and answers.
